# Mermaid Tax Invoice - Quick Start Guide

## Installation

1. Install module from Apps menu
2. Search for "Mermaid Tax Invoice"
3. Click Install

## Basic Usage

### Step 1: Add Contract Number to Invoice

1. Go to **Accounting → Customers → Invoices**
2. Create new invoice or open existing one
3. Find **Contract No** field
4. Enter contract reference (e.g., "CTR-2025-001")
5. Save invoice

### Step 2: Print Tax Invoice

1. Open the invoice
2. Click **Print** button
3. Select **Tax Invoice**
4. PDF generates automatically

## Quick Tips

- Contract number is optional
- Works with all invoice types (invoices, credit notes, etc.)
- Supports multiple currencies
- VAT calculated automatically
